# FiForesight 📈

FiForesight is an AI-driven quantitative financial forecasting application. It provides real-time market analysis, technical indicators (RSI), and 48-hour price predictions powered by **Google Gemini AI**.

The project is architected with a dedicated Python backend for high-performance data processing and a modern React frontend for professional visualization.

## 🚀 Current Features

- **Live Market Feed:** Real-time price tracking powered by the **Finnhub API**.
- **AI-Powered Forecasting:** 48-hour price range predictions and analyst notes generated by **Gemini 1.5 Flash**.
- **Technical Indicators:** Automated RSI (Relative Strength Index) calculation for momentum analysis.
- **Time-Series Database:** Persistent market data storage using **InfluxDB** for historical context.
- **Quantitative Visualization:** Interactive price history charts built with **Recharts**.
- **Modern UI:** Professional dark-mode dashboard built with **Material UI (MUI)**.

## 🛠️ Tech Stack

- **Frontend:** Next.js 14, TypeScript, Material UI (MUI), Recharts, Lucide Icons.
- **Backend:** FastAPI (Python 3.12), Pandas, NumPy, Google GenAI SDK.
- **Database:** InfluxDB (Time-series data).
- **Data Provider:** Finnhub API.
- **DevOps:** Docker (Multi-stage builds), GitHub Actions (CI/CD).

## ⚙️ Getting Started

### Prerequisites
- Node.js (Latest LTS)
- Python 3.12+
- InfluxDB instance (Local or Cloud)
- API Keys for **Finnhub** and **Google Gemini**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/WeekendDevelopment/FiForesight.git
   cd FiForesight
   ```

2. **Configure Environment Variables:**
   Create a `.env` file in the `backend` directory:
   ```env
   FINNHUB_API_KEY=your_finnhub_key
   GOOGLE_GENAI_API_KEY=your_gemini_key
   INFLUXDB_URL=http://localhost:8086
   INFLUXDB_TOKEN=your_influx_token
   INFLUXDB_ORG=your_org
   INFLUXDB_BUCKET=FiForesightBucket
   ```

3. **Install Dependencies:**
   ```bash
   pnpm install
   cd backend && pip install -r requirements.txt
   ```

4. **Run the Application:**
   ```bash
   pnpm run app:dev
   ```
   *This starts both the FastAPI backend (8000) and Next.js frontend (3000) concurrently.*
